# x86_64 PREEMPT_RT 设置指南

> 本文档描述在 x86 实机上的预期步骤；**构建链可在 ARM 主机交叉验证**，insmod 与抖动测量需本机完成。

## 1. 依赖

```bash
# PREEMPT_RT 内核（发行版示例，按实际选用）
sudo apt install linux-image-rt-amd64 linux-headers-$(uname -r) \
    clang-19 llvm-19 build-essential bc flex bison libelf-dev

export PLC_PLATFORM=x86_64
export PATH="/usr/lib/llvm-19/bin:$PATH"
```

## 2. 内核 cmdline（示例四核）

```
isolcpus=1 nohz_full=1 rcu_nocbs=1 intel_pstate=disable nosmt
```

与 `manifests/platform/x86_64.env` 中 `JITTER_PROBE_CPU=1` 一致。

## 3. 构建与加载

```bash
cd k-fusion/kfusion
bash scripts/plc_fuse__内核化主流程.sh manifests/manifest_signaltest__信号测试.env
bash scripts/ignite_fused__通用ko构建.sh manifests/manifest_signaltest__信号测试.env
sudo insmod test/signaltest_mod.ko
echo 1 | sudo tee /sys/module/signaltest_mod/parameters/shutdown_request
bash scripts/safe_rmmod_fused__安全卸载.sh signaltest_mod
```

## 4. cyclictest 主线（可选）

```bash
cd scripts/deploy
export PLC_PLATFORM=x86_64
# 按实机改 manifests/platform/x86_64.env 中 RT_NETDEV、JITTER_PROBE_CPU
DURATION_MIN=15 bash run_soak_cycletest__浸泡长测.sh
```

## 5. 在 Pi 上交叉检查（无 x86 实机）

```bash
PLC_PLATFORM=x86_64 bash scripts/platform/validate_build__平台构建验证.sh
file test/platform_x86_64_*/hello_plc_kernel.o   # 应含 x86-64
```

## 6. 与 Pi 结果对比

- **不要**直接比较 abs_max 绝对值（timer/芯片/BIOS 不同）
- **可以**比较：fuse 成功率、insmod 成功率、三基线相对趋势（同平台内）
